# 2-28차 배포 검증 체크리스트

대상: 앱 소개문(Bio) · 검수 전 게시물 타인 전체 숨김 · 로비 뉴스 티커
소요: 30~40분 · 우선순위 순서대로 진행

## 준비물

- 앱 기기 **2대** (또는 앱 1대 + 다른 기기) — 작성자와 타인을 구분해야 한다
- 스타 계정(페이지 소유자), 어드민 계정(SM)
- PC 브라우저 (웹 랜딩 확인용)

> 티커 이벤트 감지(역전·추격·점수 변화 판정)는 스펙 8건, 소개문 정규화는 백엔드 테스트 5건이 이미 덮고 있다.
> 여기서는 **테스트가 확인할 수 없는 것** — 실제 화면, 두 기기 간 노출 차이, 애니메이션, 폴링 연동 — 만 본다.

**배포 전제**: WAR와 앱 빌드를 함께 배포한다. 새 DDL은 없지만 2-27차 `star-bio.sql`(PRS_BIO 컬럼)이 운영 DB에 이미 적용돼 있어야 한다.

# 0. 배포 직후 (회귀) — 여기서 걸리면 즉시 롤백

**기존 승인 글이 사라지는 것**이 이번 변경의 최악 시나리오다 (갤러리·검색 쿼리의 검수 조건을 바꿨다).

앱에서 (타인 기기 기준):

- [ ] 로비가 정상적으로 뜬다 — VS 카드, Today's TOP, TOP 100 모두 채워짐
- [ ] 아무 스타 페이지 진입 → **기존(승인된) 피드가 전부 그대로 보인다**
- [ ] 피드 15건 이상인 스타에서 무한 스크롤이 끝까지 동작한다
- [ ] 콘텐츠 상세 진입 → 정상
- [ ] 검색(스타·콘텐츠) → 기존 승인 글이 결과에 나온다
- [ ] 프로필 사진 변경·이름 변경이 여전히 동작한다 (updateProfile 쿼리를 조건부로 바꿨다 — 회귀 포인트)

> 승인 글이 비어 보이면 `selectStarGallery` 조건 변경이 원인일 가능성이 높다. 즉시 롤백.

# 1. 검수 전 게시물 — 타인에게 전체 숨김 (기능 핵심)

2-26차의 "Under review 회색 박스"가 **타인 화면에서 완전히 사라지는 것**으로 바뀌었다.
기기 2대로 확인한다. **작성자 = 글을 올린 스타 계정, 타인 = 다른 기기**.

## 1-1. PENDING (승인 대기)

스타 계정으로 이미지 글 1건 작성 후:

| 대상 | 기대 |
|---|---|
| 작성자 | 게시물과 이미지가 **정상적으로 보인다** |
| 타인 | 게시물이 **목록에 아예 없다** — 빈 카드·회색 박스·빈 공간 없음 |
| 어드민 | 검수 목록에 뜬다 (기존 그대로) |

- [ ] 작성자 기기: 방금 쓴 글이 목록 맨 위에 보이고 이미지도 보인다
- [ ] 타인 기기: 새로고침해도 그 게시물이 **목록에 없다**
- [ ] 타인 기기: 게시물이 있던 자리에 **빈 카드나 흰 박스가 남지 않는다** — 다음 글이 바로 이어진다
- [ ] 타인 기기: 게시물 개수가 승인 글 수와 일치한다 (스크롤 끝까지)

## 1-2. 딥링크 차단 ★

이번 변경의 핵심 방어선. 목록에서 빼도 링크로 열리면 의미가 없다.

1. 작성자 기기에서 PENDING 글의 **공유 링크**를 복사
2. 타인 기기에서 그 링크로 진입

- [ ] "This post has been deleted or does not exist." 안내가 뜬다 (빈 화면 ✗, 글 내용 노출 ✗)
- [ ] 같은 링크를 작성자 기기에서 열면 **정상적으로 보인다**

## 1-3. 검색 차단 (신규로 막은 구멍)

기존에는 검수 필터가 없어 PENDING 글 본문이 검색에 노출됐다.

- [ ] 타인 기기: PENDING 글 본문의 고유 단어로 콘텐츠 검색 → **결과에 없다**
- [ ] 작성자가 승인 글로 같은 단어를 쓴 경우는 검색에 나온다 (승인 글 회귀 확인)

## 1-4. 승인 → 노출 전환

어드민에서 해당 건 **[공개]**:

- [ ] 타인 기기 새로고침 → 게시물이 **나타나고 이미지가 보인다**
- [ ] 검색에도 걸리기 시작한다

## 1-5. 거절 (기존 동작 유지)

새 이미지 글을 하나 더 올리고 어드민에서 **[거절]**:

- [ ] 작성자 기기: 게시물이 사라진다 (거절은 작성자도 못 본다 — 2-26차 그대로)
- [ ] 타인 기기: 처음부터 안 보였고 계속 안 보인다

## 1-6. 정책 확인 (버그 아님)

- [ ] **텍스트만 있는 글**(이미지 없음)은 검수 대상이 아니므로 타인에게 **즉시 보인다**
- [ ] 앱을 업데이트하지 않은 구버전 기기에서도 PENDING 글이 안 보인다 (서버에서 빼므로 앱 버전 무관)

# 2. 앱 소개문 (Bio)

## 2-1. 소유자 편집

스타 계정으로 자기 페이지 진입:

- [ ] 이름 아래에 "Add a short bio"가 보인다 (소개문이 아직 없을 때)
- [ ] 탭 → 입력창(여러 줄) → 저장 → 이름 아래에 소개문이 표시된다
- [ ] 긴 소개문은 **1줄에서 말줄임**된다 — 알약(테두리) 안에서 이름·랭킹·스탯 줄이 **위아래로 잘리지 않는다** ★
      (필 높이가 네이티브 광고 좌표와 묶여 있어 고정 100px — 밀림이 보이면 즉시 보고)
- [ ] 다시 편집 → 기존 내용(전문)이 입력창에 채워져 있다
- [ ] 전부 지우고 저장 → 소개문이 사라지고 "Add a short bio"로 돌아온다

## 2-2. 타인 화면

- [ ] 타인 기기: 소개문이 있는 스타 페이지에서 소개문 1줄이 **보인다**
- [ ] 타인 기기: 말줄임된 소개문을 **탭하면 전문이 알림창으로 뜬다**
- [ ] 타인 기기: 연필 아이콘·"Add a short bio"가 **없다** (소개문 없는 스타는 그 줄 자체가 없음)
- [ ] 소개문이 있는 스타 페이지에서 **네이티브 광고(피드 3번째 슬롯) 위치가 어긋나지 않는다** — 헤더 높이 불변 확인

## 2-3. 교차 갱신 (같은 컬럼 확인)

어드민 소개(Bio) 화면과 앱이 같은 `PRS_BIO`를 쓴다.

- [ ] 앱에서 저장한 소개문이 어드민 `/super/star/bio.do` 목록에 그대로 보인다
- [ ] 어드민에서 수정 → 앱 스타 페이지 새로고침 → 반영된다
- [ ] **웹 랜딩**: PC에서 해당 스타 랜딩을 열면 About 섹션에 같은 소개문이 나온다
- [ ] 소개문을 비운 스타의 랜딩에는 About 섹션이 아예 없다 (빈 제목 ✗)

## 2-4. 다른 필드와의 간섭 (회귀 핵심)

- [ ] 소개문만 저장 → **이름과 프로필 사진이 그대로다**
- [ ] 이름만 변경 → **소개문이 그대로다**
- [ ] 프로필 사진만 변경 → **소개문·이름이 그대로다**

# 3. 로비 뉴스 티커

## 3-1. 기본 표시

로비 진입:

- [ ] VS 카드 **바로 아래**, Today's TOP **위**에 한 줄 바가 있다
- [ ] 높이가 낮다(36px) — Today's TOP 사진·이름·순위가 기존처럼 다 보인다
- [ ] 왼쪽에 빨간 LIVE 배지, 점이 은은하게 깜빡인다 (정신없는 점멸 ✗)
- [ ] 문장이 **오른쪽에서 왼쪽으로** 흘러간다 (방송 자막처럼)
- [ ] 문장이 다 지나가면 잠깐 비었다가 다음 문장이 이어진다

## 3-2. 문구 순환 (이벤트 없을 때)

점수 변화가 없어도 멈춰 보이면 안 된다. **1~2분** 지켜본다:

- [ ] `⚔️ LIVE VS · A vs B · GAP n`, `👑 DAILY KING · ○○ holding #1` 류의 상태 문구가 번갈아 나온다
- [ ] 같은 문장이 연속으로 반복되지 않고 카드를 돌아가며 보여준다

## 3-3. 실시간 이벤트 (두 기기)

타인 기기로 VS 카드에 올라 있는 스타의 페이지를 방문해 점수를 올린다:

- [ ] 몇 초 안에(폴링 3초) 점수 변화 문장(`⚔️ A 392 : 391 B`)이나 추격 문장(`🔥 B closing in… GAP n`)이 나온다
- [ ] **역전 연출** ★: GAP이 1인 카드에서 뒤진 쪽 스타를 방문해 역전시키면 — 흐르던 문장이 끊기고 `🚨 NEW KING · ○○ takes #1!`이 **즉시** 노란색으로 나온다 (DAILY 카드 기준. GLOBAL 카드는 `⚡ LEAD CHANGE`)

> GAP 1 카드가 없으면 어드민 VS 카드 설정으로 근접한 대진을 하나 만들어 확인한다.

## 3-4. 터치

- [ ] 티커를 탭하면 VS 카드로 화면이 스크롤된다 (아래로 스크롤한 상태에서 확인)

## 3-5. 정지/재개 (배터리 보호)

- [ ] 검색·랭킹·즐겨찾기 모드로 들어가면 티커가 없다 / 돌아오면 다시 흐른다
- [ ] 스타 페이지 갔다가 돌아오면 다시 흐른다
- [ ] 앱을 백그라운드로 보냈다가 복귀해도 다시 흐른다 (멈춘 채 방치 ✗)

## 3-6. 주변 회귀

- [ ] VS 캐러셀 크로스페이드가 그대로 부드럽다 (2-26차 깜빡임 재발 ✗) — 30초 관찰
- [ ] 네이티브 광고 슬롯 위치가 티커 높이만큼 어긋나지 않는다 (광고가 뜨는 계정/조건에서)
- [ ] 로비 스크롤이 버벅이지 않는다 (티커 애니메이션 부하 확인, 저사양 Android가 있으면 그 기기로)

# 문제 발생 시

**롤백**: 이전 WAR + 이전 앱 빌드로 되돌린다. DDL 변경이 없으므로 DB는 손대지 않는다.

**증상별 1차 확인**

| 증상 | 볼 곳 |
|---|---|
| 승인 글까지 안 보임 | `selectStarGallery` 조건 — `MDR_STATUS` 값에 APPROVED 외 값이 섞였는지 |
| 작성자에게 자기 PENDING 글이 안 보임 | 앱이 `starToken`을 보내는지, `checkStarToken` 통과 여부 (isOwner=false면 타인 취급) |
| 소개문 저장이 안 됨 | 응답 `msg` 확인 — "Nothing to update"면 payload에 bio 누락, 2000자 초과면 길이 |
| 소개문 저장했더니 이름이 지워짐 | `updateProfile` 매퍼의 `<trim>` 조건 — 즉시 보고 |
| 티커가 안 보임 | VS 카드가 0장인지 (`vsCards.length > 0`일 때만 렌더) |
| 티커가 멈춰 있음 | 콘솔 오류 확인 — 구형 웹뷰 폴백(고정 표시)인지, start() 미호출인지 |
| NEW KING이 안 뜸 | 같은 대진(좌우 동일)에서 역전해야 감지된다 — 카드 대진이 폴링 사이에 교체되면 비교하지 않음 |
