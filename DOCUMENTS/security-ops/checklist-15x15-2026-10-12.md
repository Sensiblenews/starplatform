# StarPlatform 서버·보안·운영·Factory 통합 체크리스트 — 15×15 점검 결과 (2026-10-12)

클라이언트 "통합 표준 매뉴얼"의 15개 대항목 × 15개 소항목(+일일 점검 30개)을 **현재 저장소·운영 상태 기준**으로 판정했다.
판정은 코드·설정·실측으로 확인 가능한 것만 완료로 표시했다. "설정·문서만으로 PASS 금지" 원칙(7001 사전 생산준비 패키지와 동일).

**범례**
- ✅ 완료 — 코드/저장소/실측에서 확인됨
- 🟡 부분 — 코드는 있으나 운영 설정·검증이 남음, 또는 일부만 충족
- 🔧 NEEDS OPS — 서버(SSH/root)·Cloudflare·외부 계정 접근이 필요해 개발 측에서 할 수 없음 (사용자 지시: "실운영에 필요한 것 제외")
- 📄 문서/절차 — 기술 작업이 아니라 운영 절차. 문서로 제공
- ❌ 미착수 — 이번 범위 밖, 또는 전제 미확정
- ➖ 해당 없음 — 이 시스템에 그런 구성요소가 없음(큐, DB 복제 등)

**이번 작업(2026-10-12)으로 바뀐 것**: 관리자 Google OTP 이중인증(04 대항목), 서버 위험 경보·SMTP 메일(05-15, 07-02, 10 대항목, 12-11), 보안 감사 로그(01-14 일부, 02-12, 10-09, 12-14 일부), 비밀정보 점검(47).

## 즉시 조치 권고 (우선순위)

1. **비밀정보 교체** — 저장소에 있는 SMTP 앱 비밀번호와 관리자 토큰 서명 키 (S1·S3, 별도 채널 문서)
2. **OTP 배포 전제** — 운영 DB DDL 2종 실행 + `otp.encryption.key` 설정 + 서버 NTP 확인
3. **경보 수신자 설정 + 시험 메일 실수신** — 어드민 경보 센터
4. **Cloudflare 무료 플랜 점검** — HSTS·최소 TLS 1.2·Rate Limit 1규칙(관리자 로그인)·Bot Fight Mode·원본 IP 차단·Access(관리자 경로)
5. **외부 생존 감시** 등록 및 실제 알림 검증
6. 보안 헤더·세션 쿠키 Secure (설정 변경 승인 필요)
